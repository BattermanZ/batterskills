# batterskills

My agent skills, in one repo. Claude Code, Codex, Pi and Hermes all load their skills from this tree, so a skill is written once and reaches every harness.

The repo started life as a fork of Matt Pocock's skills collection and outgrew that: it now holds skills from several authors alongside my own, so the layout puts provenance first.

## Layout

```
skills/
  battermanz/   original work, organised by domain: vault, writing, personal, meta
  mattpocock/   Matt Pocock's engineering, productivity and misc buckets
  pstack/       from Lauren Tan's pstack plugin
  anthropic/    ported from claude-plugins-official
```

Each third-party tree mirrors its author's own repo layout and carries a README naming the source, plus the author's license. Updates from an author are ported by hand: diff their repo against their tree here and take what's worth taking. Nothing merges automatically, and some skills deliberately diverge from their upstream versions; the git history is the record.

## Install

```
npx skills add BattermanZ/batterskills
```

Or clone and run `scripts/link-skills.sh`, which symlinks every skill (flat, by name) into `~/.claude/skills` and `~/.agents/skills`.
